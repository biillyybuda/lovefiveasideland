# Lineup fonts

Unmodified Inter Display 4.1, by Rasmus Andersson, hosted locally for the website lineup card and PNG exporter.

- https://rsms.me/inter/font-files/InterDisplay-Medium.woff2?v=4.1
- https://rsms.me/inter/font-files/InterDisplay-SemiBold.woff2?v=4.1
- Project: https://github.com/rsms/inter
- License: `Inter-LICENSE.txt` (SIL Open Font License 1.1)

Both weights are exposed under the CSS family alias `Lineup Inter`. Keep that alias and the weights in `lib/lineup-image.ts` in sync with `app/globals.css`.
